
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, seleção aleatória, loops, condicionais e entrada de dados do usuário.

## 📝 Tarefas

### 🛠️ Preparar a Palavra e o Progresso

#### Descrição
Implemente a preparação do jogo: selecione uma palavra aleatoriamente de uma lista predefinida e mostre ao jogador quais letras ainda precisam ser adivinhadas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir cada letra ainda não adivinhada como um espaço em branco, por exemplo, `_ _ _ _`.
- Revelar as posições correspondentes quando o jogador acertar uma letra.

### 🛠️ Conduzir a Partida

#### Descrição
Crie o loop principal da partida para receber palpites, atualizar as tentativas e informar o resultado ao jogador.

#### Requisitos
O programa concluído deve:

- Solicitar palpites de letras até o jogador vencer ou esgotar as tentativas.
- Reduzir o número de tentativas restantes quando o palpite não estiver na palavra.
- Exibir quantas tentativas incorretas ainda restam.
- Encerrar a partida quando todas as letras forem adivinhadas ou não houver tentativas restantes.
- Exibir uma mensagem indicando vitória ou derrota.
